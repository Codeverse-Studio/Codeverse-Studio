# 🛒 E-Commerce Web App

Aplikasi e-commerce sederhana dengan fitur dasar seperti login, cart, dan halaman produk.

## 🚀 Fitur
- Autentikasi pengguna
- CRUD produk
- Keranjang belanja
- Dashboard admin

## 🛠️ Teknologi
Node.js, Express, MongoDB, Bootstrap

## ⚙️ Cara Menjalankan
```bash
npm install
npm start
```
